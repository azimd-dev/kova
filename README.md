Kova

Kova est un assistant IA gratuit pour Windows, créé par Azim Demirel de la ZKA.

Télécharger : https://github.com/azimd-dev/kova/releases/latest/download/Kova.zip

Le site : https://azimd-dev.github.io/kova/

Installation
Télécharge Kova.zip et extrais-le.
Double-clique sur Kova.exe.
Entre ta clé Groq gratuite (console.groq.com/keys).
Confidentialité

Ta clé et tes conversations restent sur ton ordinateur. Seul le Chat Kova utilise un serveur.

Kova est un projet personnel. Tous droits réservés.
